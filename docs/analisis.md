# Análisis de Clases - Clínica Veterinaria PetCare

| Clase candidata | Tipo (concreta, abstracta o interfaz) | Atributos principales | Responsabilidades (métodos) | Justificación |
| --- | --- | --- | --- | --- |
| Persona | abstracta | - nombre: String<br>- apellido: String<br>- telefono: String<br>- correo: String | - getNombre(), setNombre()<br>- getApellido(), setApellido()<br>- getTelefono(), setTelefono()<br>- getCorreo(), setCorreo() | Contiene los datos de contacto comunes para todos los actores humanos de la clínica, evitando duplicación de código. |
| Dueno | concreta | - direccion: String<br>- mascotas: List\<Mascota\> | - getDireccion(), setDireccion()<br>- agregarMascota()<br>- listarMascotas() | Hereda de Persona y añade la dirección particular, así como la gestión de las mascotas que le pertenecen. |
| Veterinario | concreta | - cedulaProfesional: String<br>- especialidad: String<br>- citas: List\<Cita\> | - getCedulaProfesional(), setCedulaProfesional()<br>- getEspecialidad(), setEspecialidad()<br>- atenderCita() | Hereda de Persona y añade los datos profesionales requeridos para laborar y atender citas en la clínica. |
| Recepcionista | concreta | - turno: String | - getTurno(), setTurno()<br>- agendarCita()<br>- registrarMascota() | Hereda de Persona y encapsula el turno laboral para las tareas de gestión y atención en recepción. |
| Mascota | abstracta | - nombre: String<br>- edad: int<br>- peso: double<br>- dueno: Dueno<br>- historialClinico: HistorialClinico | - getNombre(), setNombre()<br>- getEdad(), setEdad()<br>- getPeso(), setPeso()<br>- hacerSonido() (abstracto) | Clase base abstracta que agrupa las características y validaciones comunes (como edad y peso positivos) de los animales. |
| Perro | concreta | - raza: String<br>- nivelEnergia: String | - getRaza(), setRaza()<br>- getNivelEnergia(), setNivelEnergia()<br>- hacerSonido() | Hereda de Mascota, implementa el sonido característico y añade atributos específicos como raza y nivel de energía. |
| Gato | concreta | - esDomestico: boolean | - isEsDomestico(), setEsDomestico()<br>- hacerSonido() | Hereda de Mascota, define su sonido propio y su condición de domesticación. |
| Ave | concreta | - longitudAlas: double | - getLongitudAlas(), setLongitudAlas()<br>- hacerSonido() | Hereda de Mascota, representa a las aves exóticas añadiendo la medida de sus alas y su respectivo sonido. |
| HistorialClinico | concreta | - serviciosRealizados: List\<Facturable\> | - agregarServicio()<br>- mostrarHistorial() | Agrupa el registro médico e histórico de los servicios aplicados a la mascota mediante composición estricta. |
| Cita | concreta | - fechaHora: LocalDateTime<br>- estado: String<br>- mascota: Mascota<br>- veterinario: Veterinario<br>- consultorio: Consultorio<br>- servicio: Facturable | - programar()<br>- atender()<br>- cancelar() | Relaciona de forma independiente a una mascota con un veterinario en un consultorio y tiempo determinado, controlando estados. |
| Clinica | concreta | - nombre: String<br>- veterinarios: List\<Veterinario\><br>- recepcionistas: List\<Recepcionista\><br>- consultorios: List\<Consultorio\><br>- citas: List\<Cita\> | - agregarVeterinario()<br>- agregarConsultorio()<br>- buscarCita() | Contenedor principal del sistema que gestiona el personal, los espacios físicos y las citas programadas. |
| Consultorio | concreta | - numero: int | - getNumero(), setNumero() | Representa las salas numeradas de la clínica, creadas y poseídas exclusivamente por la misma (composición). |
| ConsultaGeneral | concreta | - tarifaBase: double | - calcularCosto() | Modela las consultas ordinarias de la clínica implementando la interfaz Facturable para calcular su costo base. |
| Vacunacion | concreta | - costoVacuna: double<br>- nombreVacuna: String | - calcularCosto() | Modela el servicio de aplicación de vacunas implementando Facturable, sumando la tarifa de la vacuna aplicada. |
| Cirugia | concreta | - complejidad: String<br>- horasQuirofano: double | - calcularCosto() | Modela los procedimientos quirúrgicos complejos implementando Facturable; su costo depende de las horas de quirófano y nivel. |
| Comprobante | concreta | - idComprobante: int<br>- total: double<br>- fechaEmision: LocalDate<br>- citaAsociada: Cita | - generarComprobante()<br>- mostrarDetalle() | Almacena y muestra el recibo generado al finalizar satisfactoriamente una cita atendida, tomando el costo del servicio. |
| Facturable | interfaz | (Ningún atributo, solo firma de métodos) | - calcularCosto(): double | Define el contrato común para que cualquier servicio médico (`ConsultaGeneral`, `Vacunacion`, `Cirugia`) deba implementar obligatoriamente el cálculo de su costo. |
| Main | concreta | (Variables estáticas de control y colecciones en memoria) | - main(String[] args)<br>- mostrarMenu() | Clase principal ejecutable que gestiona el flujo del sistema mediante un bucle de menús y validaciones en consola. |
