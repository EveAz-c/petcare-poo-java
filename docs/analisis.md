# Análisis de Clases - Clínica Veterinaria PetCare

| Clase candidata | Tipo (concreta, abstracta o interfaz) | Atributos principales | Responsabilidades (métodos) | Justificación |
| --- | --- | --- | --- | --- |
| Persona | abstracta | - nombre: String<br>- apellido: String<br>- telefono: String<br>- correo: String | - getNombre(), setNombre()<br>- getApellido(), setApellido()<br>- getTelefono(), setTelefono()<br>- getCorreo(), setCorreo() | Contiene los datos de contacto comunes para todos los actores humanos de la clínica, evitando duplicación de código. |
| Dueno | concreta | - direccion: String<br>- mascotas: List\<Mascota\> | - getDireccion(), setDireccion()<br>- agregarMascota()<br>- listarMascotas()<br> - eliminarMascota()| Hereda de Persona y añade la dirección particular, así como la gestión de las mascotas que le pertenecen. |
| Veterinario | concreta | - cedulaProfesional: String<br>- especialidad: String<br>- citas: List\<Cita\> | - getCedulaProfesional(), setCedulaProfesional()<br>- getEspecialidad(), setEspecialidad()<br>- atenderCita() | Hereda de Persona y añade los datos profesionales requeridos para laborar y atender citas en la clínica. |
| Recepcionista | concreta | - turno: String | - getTurno(), setTurno()<br>- agendarCita()<br>- registrarMascota() | Hereda de Persona y encapsula el turno laboral para las tareas de gestión y atención en recepción. |
| Mascota | abstracta | - nombre: String<br>- edad: int<br>- peso: double<br>- dueno: Dueno<br>- historialClinico: HistorialClinico | - getNombre(), setNombre()<br>- getEdad(), setEdad()<br>- getPeso(), setPeso()<br>- hacerSonido() (abstracto) | Clase base abstracta que agrupa las características y validaciones comunes (como edad y peso positivos) de los animales. |
| Perro | concreta | - raza: String<br>- nivelEnergia: String | - getRaza(), setRaza()<br>- getNivelEnergia(), setNivelEnergia()<br>- hacerSonido() | Hereda de Mascota, implementa el sonido característico y añade atributos específicos como raza y nivel de energía. |
| Gato | concreta | - esDomestico: boolean | - isEsDomestico(), setEsDomestico()<br>- hacerSonido() | Hereda de Mascota, define su sonido propio y su condición de domesticación. |
| Ave | concreta | - longitudAlas: double | - getLongitudAlas(), setLongitudAlas()<br>- hacerSonido() | Hereda de Mascota, representa a las aves exóticas añadiendo la medida de sus alas y su respectivo sonido. |
| HistorialClinico | concreta | - serviciosRealizados: List\<Facturable\> | - agregarServicio(Facturable servicio)<br>- mostrarHistorial()<br>- getServiciosRealizados(), setServiciosRealizados() | Agrupa el registro médico e histórico de los servicios aplicados a la mascota mediante composición estricta. |
| Cita | concreta | - fechaHora: LocalDateTime<br>- estado: String<br>- mascota: Mascota<br>- veterinario: Veterinario<br>- consultorio: Consultorio<br>- servicio: Facturable | - atender()<br>- cancelar()<br>- getFechaHora(), setFechaHora()<br>- getEstado(), setEstado()<br>- getMascota(), setMascota()<br>- getVeterinario(), setVeterinario()<br>- getConsultorio(), setConsultorio()<br>- getServicio(), setServicio() | Relaciona de forma independiente a una mascota con un veterinario en un consultorio y tiempo determinado, controlando estados y el servicio médico aplicado. |
| Clinica | concreta | - nombre: String<br>- mascotas: List\<Mascota\><br>- veterinarios: List\<Veterinario\><br>- recepcionistas: List\<Recepcionista\><br>- consultorios: List\<Consultorio\><br>- citas: List\<Cita\> | - registrarCita()<br>- darDeBajaMascota()<br>- consultarCobrosPorVeterinario()<br>- consultarCobrosPorMascota()<br>- agregarConsultorio()<br>- agregarRecepcionista()<br>- getNombre(), setNombre()<br>- getMascotas(), getVeterinarios(), getRecepcionistas(), getConsultorios(), getCitas() | Contenedor principal del sistema que gestiona las mascotas, el personal (veterinarios y recepcionistas), los espacios físicos únicos, las citas programadas y el cálculo de cobros independientes. |
| Consultorio | concreta | - numero: int<br>- descripcion: String | - getNumero(), setNumero()<br>- getDescripcion(), setDescripcion()<br>- toString() | Representa las salas numeradas y equipadas de la clínica, creadas y poseídas exclusivamente por la misma (composición). |
| ConsultaGeneral | concreta | - costo: double<br>- diagnostico: String<br>- observaciones: String | - calcularCosto()<br>- getCosto(), setCosto()<br>- getDiagnostico(), setDiagnostico()<br>- getObservaciones(), setObservaciones()<br>- toString() | Modela las consultas ordinarias de la clínica implementando la interfaz Facturable para calcular el costo, e incorpora el diagnóstico y observaciones médicas. |
| Vacunacion | concreta | - costoVacuna: double<br>- nombreVacuna: String | - calcularCosto()<br>- getCostoVacuna(), setCostoVacuna()<br>- getNombreVacuna(), setNombreVacuna()<br>- toString() | Modela el servicio de aplicación de vacunas implementando Facturable, sumando la tarifa de la vacuna aplicada. |
| Cirugia | concreta | - complejidad: String<br>- horasQuirofano: double | - calcularCosto()<br>- getComplejidad(), setComplejidad()<br>- getHorasQuirofano(), setHorasQuirofano()<br>- toString() | Modela los procedimientos quirúrgicos implementa Facturable; su costo depende de las horas de quirófano y nivel. |
| Comprobante | concreta | - idComprobante: int<br>- total: double<br>- fechaEmision: LocalDate<br>- citaAsociada: Cita | - generarComprobante()<br>- mostrarDetalle()<br>- getIdComprobante(), setIdComprobante()<br>- getTotal(), setTotal()<br>- getFechaEmision(), setFechaEmision()<br>- getCitaAsociada(), setCitaAsociada()<br>- toString() | Almacena y muestra el recibo generado al finalizar satisfactoriamente una cita atendida, tomando el costo del servicio. |
| Facturable | interfaz | ninguno | - calcularCosto(): double | Define el contrato común para que cualquier servicio médico (ConsultaGeneral, Vacunacion, Cirugia) deba implementar obligatoriamente el cálculo de su costo. |
| Main | concreta | (Variables estáticas de control y colecciones en memoria) | - main(String[] args)<br>- mostrarMenu() | Clase principal ejecutable que gestiona el flujo del sistema mediante un bucle de menús y validaciones en consola. |
